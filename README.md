# Eladio Rojas Harasic · Paid Media & Growth Specialist

Portafolio bilingüe (español / English) con casos reales de Meta Ads, Google Ads y email marketing en ecommerce y generación de leads.

**Sitio:** https://eladioroha.github.io

## Casos

| Marca | Rubro | Resultado principal |
|---|---|---|
| Clínica Dr. Carrasco | Cirugía estética | Tasa de cierre de 2% a 7%, CPL de ~$3.000 a ~$1.000 |
| Club Gordos · GRDS · Fast no Junk | Franquicias gastronómicas | ~150 reuniones de venta y ~6 franquicias vendidas |
| SkyStore | Vaporizadores | ROAS ~10x en 3 meses en una categoría restringida |
| Herramientas Express | Ferretería online | De un Cyber sin ventas a ~$17 M en el siguiente |
| Underfive | Snacks saludables | Remarketing con ROAS 16,4x + email marketing en Klaviyo |
| C. del Pilar | Moda | Diagnóstico y plan para escalar una cuenta con ROAS 22,5x |

Cifras aproximadas, reconstruidas a partir de los reportes de cada cuenta.

## Stack

Astro + Tailwind CSS, sitio estático publicado con GitHub Actions en GitHub Pages. Los casos viven en `src/data/casos.ts` (un solo archivo, ambos idiomas).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```
